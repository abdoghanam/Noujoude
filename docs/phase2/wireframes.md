# المرحلة 2 — تصميم الصفحات (Wireframes)

- **الحالة:** ✅ وصفيّ (ASCII) — لا كود — **اعتُمد ضمن GATE-P2-2026-10-14 (قبول مشروط)**. مرتبط بخريطة Q1-A في `docs/phase1/requirements.md` §2 وبنظام التصميم في `design-system.md`.
- **اللغة:** كل الشاشات ثنائية اللغة بمحتوى متكافئ (D4/Q2-A) — التمثيل أدناه بلغة واحدة كنموذج، والترجمة ليست ترقية جودة.
- **الاتجاه:** الرسومات بمنطق RTL (بداية = يمين). في LTR ينعكس التخطيط تلقائيًا بخصائص CSS المنطقية — لا نسخة ثانية من المخطط.

---

## 1. الهيكل العام (كل الصفحات)

```text
┌─────────────────────────────────────────────┐
│ Skip link (يظهر عند التركيز)                 │
├─────────────────────────────────────────────┤
│ HEADER (sticky):                             │
│   [Logo: NOUJOUDE — نجود]  الرئيسية المقالات  │
│   عن المنصة  تواصل          [AR｜EN]          │
│   (جوال: [Logo] [≡ قائمة]  [AR｜EN])          │
├─────────────────────────────────────────────┤
│                                             │
│              <main id="content">            │
│              (يختلف حسب الصفحة)              │
│                                             │
├─────────────────────────────────────────────┤
│ FOOTER:                                      │
│   عن المنصة · تواصل · privacy · terms         │
│   © 2026 NOUJOUDE — نجود                     │
└─────────────────────────────────────────────┘
```

- **الجوال أولًا:** التصميم الأساسي عند 375px، ثم 768px، ثم 1440px.
- التنقل ينهار لقائمة على ≤767px (بنافذة `<dialog>` أو `<details>` — يُحدَّد في المرحلة 3).
- مبدّل اللغة يظهر في Header في كل الحالات ويحافظ على المسار النسبي.

## 2. الصفحة الرئيسية `/[locale]`

**الغرض:** تعريف المحتوى + أحدث المقالات + دعوة للاستكشاف (Q1-A #1)

```text
375px (جوال)                    1440px (كمبيوتر)
┌───────────────────┐           ┌──────────────────────────────────────┐
│ Hero              │           │ Hero (عمودان: نص)                     │
│ اسم العلامة       │           │ اسم العلامة — وعد المحتوى              │
│ وعد المحتوى       │           │ [تصفّح المقالات]                       │
│ [تصفّح المقالات]  │           ├──────────────────────────────────────┤
├───────────────────┤           │ أحدث المقالات (شبكة 3 أعمدة)          │
│ أحدث المقالات     │           │ ┌──────┐ ┌──────┐ ┌──────┐          │
│ ┌───────────────┐ │           │ │Card 1│ │Card 2│ │Card 3│          │
│ │  Card 1       │ │           │ └──────┘ └──────┘ └──────┘          │
│ ├───────────────┤ │           ├──────────────────────────────────────┤
│ │  Card 2       │ │           │ التصنيفات (5 — D3-B)                 │
│ ├───────────────┤ │           │ [طوابع][عملات][فن][تحف][تذكارات]     │
│ │  Card 3       │ │           └──────────────────────────────────────┘
│ └───────────────┘ │
├───────────────────┤
│ التصنيفات (5)      │
│ [طوابع][عملات]...  │
└───────────────────┘
```

- **768px:** المقالات شبكة عمودين · قائمة التنقل قد تبقى مفتوحة.
- التصنيفات: تصفية `/articles` — لا تصنيف خارج القائمة الخمسة.
- الحالة الفارغة (لا مقالات): رسالة ثنائية اللغة + رابط عن المنصة.

## 3. أرشيف المقالات `/[locale]/articles`

**الغرض:** قائمة/شبكة كل المقالات مع تصفية بالوسوم/التصنيف (Q1-A #2)

```text
375px                              1440px
┌─────────────────┐                ┌──────────────────────────────────┐
│ h1: المقالات     │                │ h1: المقالات                       │
│ [فلاتر: تصنيفات]│                │ [تصنيفات ▾] [وسوم ▾]  نتائج: 24   │
│ [فلاتر: وسوم]   │                ├──────────────────────────────────┤
├─────────────────┤                │ ┌────┐ ┌────┐ ┌────┐ ┌────┐     │
│ ┌─────────────┐ │                │ │Card│ │Card│ │Card│ │Card│     │
│ │ Card 1      │ │                │ └────┘ └────┘ └────┘ └────┘     │
│ ├─────────────┤ │                │ ┌────┐ ┌────┐ ┌────┐ ┌────┐     │
│ │ Card 2      │ │                │ │Card│ │Card│ │Card│ │Card│     │
│ └─────────────┘ │                ├──────────────────────────────────┤
│ [تحميل المزيد]  │                │ [‹ 1 2 3 ›]                       │
└─────────────────┘                └──────────────────────────────────┘
```

- الفلاتر تحافظ على الرابط (رابط قابل للمشاركة) — منطق يُنفَّذ في المرحلة 3.
- 768px: فلاتر في صف واحد + شبكة عمودين.

## 4. صفحة المقال `/[locale]/articles/[slug]`

**الغرض:** قراءة MDX (Q1-A #3)

```text
375 / 1440 (عمود قراءة مركزي)
┌────────────────────────────────────┐
│ [الرئيسية › المقالات › تصنيف]       │  breadcrumb
│ h1: عنوان المقال                    │
│ 2026-10-14 · [تصنيف] · [وسوم]       │  metadata
├────────────────────────────────────┤
│                                    │
│  نص المقال — عمود 65–75 حرفًا/سطر  │
│  ارتفاع سطر عربي 1.8+              │
│  صور: alt وصفي، حد أقصى العرض      │
│                                    │
├────────────────────────────────────┤
│ [مقالات ذات صلة: 3 بطاقات]          │
│ ↺ بديل اللغة (نفس slug)            │
└────────────────────────────────────┘
```

- **768px+:** العمود موسّع ضمن حدّ 65–75ch مع هوامش واسعة (قراءة طويلة).
- عنوان `h1` واحد فقط — سلامة الهرمية (Q3-A).
- المقال بلا نسخة مقابلة → **لا يُنشر أصلًا** (آلية بناء Q2-A، تُختبر في المرحلة 3)؛ الرابط المكسور → 404.

## 5. عن المنصة `/[locale]/about`

**الغرض:** تعريف بالمنصة/المالك — **الهيكل معتمد، المحتوى الفعلي D5 مؤجل** (Q1-A #4)

```text
┌────────────────────────────┐
│ h1: عن المنصة              │
│ نبذة (نص D5 مؤجل —        │  ← placeholder حتى يُزوَّد المحتوى
│   يُكتب حينها)             │
│ الرسالة / القيم (من الهوية) │  ← من لوح الهوية عند حفظه
│ [صورة — تُستبدل بصور حقيقية]│
└────────────────────────────┘
```

- لا ادّعاء ببيانات مالك مختلقة (D5).

---

## 6. تواصل `/[locale]/contact`

**الغرض:** قناة تواصل — **بدون خادم في النسخة الأولى** (Q1-A #5)

```text
┌────────────────────────────┐
│ h1: تواصل                  │
│ نص ترحيبي                  │
│ [رابط بريد مباشر]  ← رابط   │
│   mailto: أو خدمة لاحقًا    │
│   بموافقة منفصلة            │
└────────────────────────────┘
```

- لا نموذج POST بدون خادم/خدمة معتمدة. أي إضافة خدمة = نطاق جديد (موافقة).

---

## 7. privacy / terms `/[locale]/privacy|terms`

**الغرض:** هيكل موحّد — **المحتوى القانوني النهائي مؤجل** (Q1-A #6/#7)

```text
┌────────────────────────────┐
│ h1: سياسة الخصوصية / الشروط│
│ [نص قانوني — مؤجل NEEDS     │
│  USER INPUT — لا يُختلق]    │
│ تُحقن أقسام عند الاعتماد    │
└────────────────────────────┘
```

- الزر/الرابط في Footer موجودان من البداية (الهيكل معتمد) — الصفحة تعرض حالة «قيد الإعداد» مهذّبة حتى اعتماد النص.

## 8. صفحة 404 (أي مسار غير مطابق)

**الغرض:** 404 فعلية عبر `not-found.tsx` (الجذر + لكل locale) — **لا مسار `/404` مستقل** (Q1-A #8)

```text
┌────────────────────────────┐
│ 404                        │
│ الصفحة غير موجودة           │
│ [العودة للرئيسية]           │
│ ↺ بديل اللغة               │
└────────────────────────────┘
```

- **شرط لاحق (يُختبر في المرحلة 5):** `GET /fr` → 404 (وليس 200) · مسار عميقة غير معروفة → 404 · `noindex` عند استخدام `global-not-found`.
- التحقق من صلاحية locale داخل مسار العرض قبل بدء البث → `notFound()` (توثيق Next.js الرسمي — nextjs.org/docs/app/api-reference/functions/not-found).

## 9. `/sitemap.xml` + `/robots.txt` (Q1-A #9)

- غير مرئية — توليد من فهرس المحتوى نفسه (`docs/phase1/architecture.md` §6)، سجلات باللغتين + `hreflang` + `xhtml:link` alternates.
- `/rss.xml` 💡 غير معتمد (Q1-A #10) — لا يُصمَّم حتى اعتماده.
