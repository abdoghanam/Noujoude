## 3. معايير قبول بوابة المرحلة 2 (GATE-P2 — تُفحص عند طلب إغلاقها)

1. ✅ نظام بصري يغطي: ألوان + خطوط + مقياس + مكوّنات + توثيق حالة الوضع الداكن (خيار 💡: إن اعتمد لاحقًا يُنفَّذ لكل الصفحات دون استثناء).
2. ✅ كل تركيبة نص/خلفية موثّقة بنِسَب تباين فعليّة ≥ 4.5:1 (عادي) أو ≥ 3:1 (كبير) — **محسوبة ومتحقق منها في `design-system.md`**.
3. ✅ كل صفحة من خريطة Q1-A لها wireframe + حالات الجوال/اللوح/الكمبيوتر.
4. ✅ RTL/LTR معماريًا في التصميم (خصائص منطقية، لا انعكاس يدوي).
5. ✅ لا كود ولا حزم — إثبات بالبحث (لا `package.json`/`app/` بعد).
6. ❓ أصول الشعار + حفظ لوح الهوية كملف — تُسدَّد قبل المرحلة 3.
7. الموافقة النهائية على الإغلاق: **إذن كتابي صريح من المدير** (الصمت ليس موافقة).

## 4. قيود موروثة من المرحلة 1 تُطبَّق في التصميم

- **D4/Q2-A:** العربية والإنجليزية متساويتان — كل عنصر تصميمي له حالتان RTL/LTR بنفس العمق.
- **Q3-A:** WCAG 2.2 AA بوابة قبول — التصميم يُصمَّم ملتزمًا لا مُصلَّحًا لاحقًا.
- **D3-B:** تصنيفات المحتوى محصورة في الخمسة المعتمدة (Stamps · Coins · Art · Antiques · Memorabilia) — لا تصنيف سادس في التنقل أو التصفية.
- **الصور:** صور اللوح المولَّدة بالذكاء الاصطناعي مزاجية فقط — تُستبدل بصور حقيقية قبل الإطلاق (مسجَّل في `docs/phase1/decisions-log.md` §2).
- **12 أسبوعًا:** خطة اللوح الزمنية غير معتمدة — الحاكم نموذج المراحل والبوابات.
