# خطة توثيق Node.js والأدوات (متطلب المستخدم — بند C)

- **الحالة:** وثيقة توثيقية فقط — **لم يُنفَّذ أي تغيير على النظام.**
- **التنفيذ يتطلب موافقة صريحة من المستخدم لكل بند.**

---

## 1. تقييم الحاجة إلى ترقية Node.js

| البند | القيمة |
|---|---|
| Node المثبَّت | **v24.19.0 LTS** (`C:\Program Files\nodejs\node.exe`) |
| المتطلب لـ `next@16.4.0` | `engines: {"node": ">=20.9.0"}` (مصدر: npm registry — 2026-10-14) |
| المتطلب لـ `typescript@7.0.2` | `engines: {"node": ">=16.20.0"}` |
| أحدث LTS متاح | v24.21.0 |

### الخلاصة: **لا حاجة لترقية Node — الإصدار الحالي متوافق.**

أي ترقية إلى v24.21.0 (فقط patch) اختيارية للحصول على آخر التصحيحات، وليست شرطًا للعمل.

**التراجع (Rollback):** غير مطلوب — لم يُغيَّر شيء.

## 2. المشكلة الفعلية: ملفات system32 التالفة تحجب الأدوات

في بيئة هذا الجهاز (فحص 2026-10-14) رُصد أن `C:\WINDOWS\system32` تسبق غيرها في PATH، لذا حل مشكلة "الأوامر العارية لا تعمل" على هذا الجهاز يكون بإحدى الطريقتين:

### الخيار 1 — إصلاح على مستوى المشروع (لا يحتاج موافقة نظامية) — **موصى به**

إضافة ملف `scripts/use-node.ps1` داخل المشروع يضيف مسار Node الحقيقي إلى PATH داخل جلسة PowerShell فقط:

```powershell
# scripts/use-node.ps1 — تأثيره على الجلسة الحالية فقط، لا يعدّل النظام
$env:Path = "C:\Program Files\nodejs;" + $env:Path
node --version   # v24.19.0
```

- **الملفات المتأثرة:** ملف واحد جديد داخل `D:\NUOJED\scripts\` فقط.
- **التراجع:** حذف الملف أو إغلاق الجلسة — لا أثر دائم.
- **النطاق:** أي أمر نُشغّله من جلسة مُهيّأة عبر هذا السكربت سيعمل بشكل صحيح.

### الخيار 2 — إصلاح على مستوى النظام (يتطلب موافقة صريحة)

حذف/إعادة تسمية الملفين التالفين:

| الملف | الإجراء |
|---|---|
| `C:\WINDOWS\system32\node` (0 بايت) | حذف أو إعادة تسمية إلى `node.bak` |
| `C:\WINDOWS\system32\npm` (50 بايت، مقطع JS) | حذف أو إعادة تسمية إلى `npm.bak` |

- **التراجع:** إعادة التسمية إلى أسمائها الأصلية (لهذا أفضّل `.bak` على الحذف).
- **المخاطر:** ملفات في مجلد نظام — قد تكون منشأة بأداة معيبة (مقطع Vercel Analytics يشير لخطأ في مسار كتابة سابق). إن كانت هناك أداة تعتمد عليها فستتأثر.
- **⚠️ لن يُنفَّذ هذا دون موافقة صريحة موثقة.**

### القرار المقترح

| الخيار | التوصية |
|---|---|
| الخيار 1 (مشروع) | ✅ نفّذه ضمن المرحلة 3 كجزء من بنية المشروع |
| الخيار 2 (نظام) | 🔶 مطروح للمستخدم — ننصح به لاحقًا بعد نجاح المشروع، لكنه ليس شرطًا |

## 3. خلاصة بند C

| البند | النتيجة |
